# 🚀 Akshay Kumar Sharma - Portfolio

A stunning, modern portfolio website built with Next.js, Framer Motion, Magic UI components, and Hero UI.

## ✨ Features

- **Smooth Scrolling Animations**: Apple-like scroll effects powered by Framer Motion
- **Interactive UI Components**:
  - Floating Navigation Bar
  - Text Generation Effect
  - Spotlight Effects
  - Background Beams
  - Moving Border Buttons
  - Hover Card Effects
  - Bento Grid Layout
- **Fully Responsive**: Works beautifully on all devices
- **SEO Optimized**: Meta tags and Open Graph support
- **Dark Mode**: Beautiful dark theme throughout
- **Performance**: Built with Next.js for optimal loading speed

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Tabler Icons
- **UI Libraries**:
  - Magic UI (animated components)
  - Hero UI (component library)
  - Custom components from various sources

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎨 Sections

1. **Hero**: Eye-catching intro with spotlight and text effects
2. **About**: Professional summary
3. **Experience**: Detailed work history with animations
4. **Projects**: Featured projects with hover effects
5. **Skills**: Technical skills showcase
6. **Contact**: Get in touch section

## 🎯 Customization

You can easily customize the content by editing the data in `app/page.tsx`:

- Update `experiences` array for work history
- Modify `projects` array for your projects
- Change `skills` array for your skill set
- Edit personal information in the hero section
